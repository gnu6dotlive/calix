# Security Policy

## Supported Versions

Calix is pre-1.0. We provide active security fixes for the latest code on the `main`
branch.

| Version | Supported |
|---|---|
| >= 0.1.0 (main) | :white_check_mark: |
| < 0.1.0 | :x: |

## Reporting a Vulnerability

We take the security of Calix and its interaction with root privileges (via Polkit and ALPM) seriously.

If you discover a security vulnerability or privilege escalation bug:

1. **Do not disclose it publicly in an open issue.**
2. Please open a [GitHub Security Advisory](https://github.com/tension-atoi/calix/security/advisories/new) on this repository, or contact the maintainer directly.
3. Include details on how to reproduce the issue, the affected components, and potential impact.

We will review, acknowledge, and work to resolve reported vulnerabilities promptly.
