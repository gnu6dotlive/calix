# A question for the other three

The seven sources are not interchangeable: an ALPM package has no build recipe,
a Cargo crate has no repository to be removed from, an AppImage has no
dependencies to show.

**When a user lands on a source whose operations differ — or on an operation a
source does not support at all — where does the interface tell them what they
cannot do here, without turning every screen into a list of disclaimers?**
