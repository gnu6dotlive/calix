# A question for the other three

How far should a package manager show the command it will actually run? Putting
`sudo pacman -Syu --needed ripgrep` on the screen is honest about what happens, but it
also makes the product read as a terminal wearing a GUI — and the command is only
honest for one of the seven sources.

And, on the same subject: is there a way to say "173,306 packages exist" without
printing a number?
